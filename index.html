Try asking

How it works

The chat window has two modes. Both answer through the same "front desk" code, which reads the spa's data and the booking calendar, so the answers always match the real menu and the real free times.

  1. 1. Customer asks"Can I book a foot massage on Friday at 3pm?"
  2. 2. UnderstandDemo mode matches keywords, dates and times. AI mode lets GPT read the message.
  3. 3. Check real dataThe front desk looks up prices, hours and free times, and checks every booking rule.
  4. 4. Answer or bookThe reply uses only what the front desk returned. Bookings get a unique code.

Demo mode (this page)

Runs completely in your browser, with no server and no AI key, so anyone can try it for free.

  • Recognises what you want: prices, hours, location, booking, cancelling
  • Understands dates and times like "next Friday", "25 Dec", "3:30pm"
  • Asks for missing details one at a time, then confirms before booking
  • Bookings are saved in this browser only

AI mode (with the Node.js server)

The server sends the conversation to OpenAI with tools: functions the AI may call to get real data.

  • Understands any wording, including Thai
  • The API key stays on the server and is never sent to the browser
  • Instructions forbid guessing; all facts come from tool results
  • Rate limiting and message size limits protect the API key from abuse

The AI's tools

ToolWhat it does
list_servicesReturns treatments with real prices and lengths, optionally for one category
get_spa_infoOpening hours, address, directions, payment, parking and policies
check_availabilityFree start times for a treatment on a date (today up to 60 days ahead)
create_bookingBooks a time after checking it's still free, the name and the Thai phone number
cancel_bookingCancels a booking, but only with both the booking code and the matching phone number
